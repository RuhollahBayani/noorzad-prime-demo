# Noorzad Prime Real Estate (demo)

Single-page demo concept website for a Dubai real estate company.

**This is a demo.** Listings, prices, people, statistics, testimonials, licence and permit numbers, and the WhatsApp number are placeholders. The page is set to `noindex`. Replace all placeholders and have fees, visa wording and advertising rules reviewed before any real launch.

- Languages: English, Arabic, Russian, Chinese
- Currencies: AED, USD, EUR, GBP, INR, CNY, RUB (indicative rates, 19 Oct 2026)
- Photos: Wikimedia Commons (credits listed in the page footer)

Open `index.html` in a browser. No build step.
